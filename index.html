Proyectos

  • Detección de fraude con tarjeta de crédito

    Python, scikit-learn, XGBoost

    1.8 millones de transacciones donde solo el 0.58% son fraude. Hice el análisis exploratorio, creé variables de hora, edad y distancia, validé respetando las fechas y comparé cuatro modelos.

    Random Forest con AUC-PR de 0.88: detecta el 85% de los fraudes.

    Ver el código en GitHub

  • Telecom: clientes que van a cancelar

    Python, scikit-learn, XGBoost, SMOTE

    Uní cuatro tablas de clientes, analicé qué perfiles cancelan más y comparé modelos con validación cruzada dentro de Pipelines. Ajusté XGBoost con GridSearch y el umbral de decisión.

    AUC-ROC de 0.91: encuentra a 3 de cada 4 clientes que se van.

    Ver el código en GitHub

  • OilyGiant: dónde abrir 200 pozos de petróleo

    Python, regresión lineal, bootstrapping

    Predije las reservas de tres regiones con regresión lineal y simulé 1000 exploraciones con bootstrapping para estimar la ganancia y el riesgo de cada una.

    Región recomendada: 4.8 millones USD de ganancia promedio con 2% de riesgo de pérdida.
